# Historical archive — legacy Felifox references

**Historical only. Not current design direction. Not browser screenshots.**

These are the four original supplied reference PNGs from the earlier Felifox
party-cat / flaming-yarn direction. They have been moved here without any
retouching, recompression, or filename changes, to preserve provenance.
The filenames are retained as supplied; they are not evidence that the new
Felinaut boards were generated by an external image service.

The old character, party hats, flame-shaped yarn and branding are obsolete.
Some boards depict speculative controls or features; their presence is **not**
evidence that bookmarks, downloads, private browsing, sync, blocking, or any
other depicted capability exists in the browser. They must not be used as
current product claims.

Use [`../../../BRAND.md`](../../../BRAND.md) via the repository root's brand
guide and the active [`../../README.md`](../../README.md) reference index
instead. The active Felinaut boards are reproducible compositions of the
canonical happy astronaut-cat SVGs and all six current Rust theme palettes.
